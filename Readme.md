# README_NSSP-Fetch

Инструмент на Python для загрузки и подготовки данных
CDC NSSP Emergency Department Visit Trajectories.

Проект позволяет получить исходные данные, отфильтровать их по штату
Техас и подготовить отдельные CSV-файлы для дальнейшего анализа
и визуализации, в том числе в Tableau.

Работа выполняется через Python-скрипты - без базы данных и
не требует регистрации пользователя.

## Возможности

* Загрузка исходных данных CDC NSSP
* Получение данных через Socrata API
* Фильтрация данных по штату Техас
* Выделение данных за 2024 год
* Очистка данных и удаление ненужных столбцов
* Сохранение результатов в формате CSV
* Подготовка данных для дальнейшего анализа и визуализации
* Использование результатов в Tableau
* Дополнительный анализ данных с помощью Python

## Требования

* Python 3.8 или новее
* pip
* Доступ в интернет для загрузки данных
* Около нескольких сотен МБ свободного места в зависимости
  от размера загружаемых CSV-файлов

Основные библиотеки:

* pandas
* requests
* numpy
* scikit-learn
* scipy
* matplotlib

## Установка

1. Клонируйте репозиторий:

   ```
   git clone https://github.com/malonekt/NSSP-Fetch.git
   cd NSSP-Fetch
   ```

2. Создайте виртуальное окружение:

   ```
   python -m venv venv
   ```

3. Активируйте виртуальное окружение:

   Linux/macOS:

   ```
   source venv/bin/activate
   ```

   Windows:

   ```
   venv\Scripts\activate
   ```

4. Установите необходимые библиотеки:

   ```
   pip install pandas requests numpy scikit-learn scipy matplotlib
   ```

## Загрузка данных

Для загрузки исходного набора данных запустите:

```
python nssp_fetch_state_tx.py
```

Скрипт загружает данные CDC NSSP и сохраняет исходный CSV-файл
в директорию `outputs/`.

## Фильтрация данных

После загрузки исходного файла выполните:

```
python filter_nssp_tx.py
```

Скрипт:

* оставляет данные, относящиеся к Техасу;
* формирует выборку за 2024 год;
* удаляет ненужные технические поля;
* сохраняет очищенные CSV-файлы.

Основные результаты находятся в директории:

```
outputs/
```

В частности, создаются файлы:

```
nssp_tx_all_years.csv
nssp_tx_2024.csv
nssp_tx_all_years_clean.csv
nssp_tx_2024_clean.csv
```

## Анализ данных

Для запуска дополнительного анализа используйте:

```
python nssp_fetch_and_analysis.py
```

Скрипт предназначен для проверки данных, отладки и выполнения
дополнительных аналитических операций.

Для анализа используются библиотеки NumPy, SciPy, scikit-learn
и Matplotlib.

## Работа с Tableau

Подготовленные CSV-файлы можно использовать для визуализации
данных в Tableau.

Для анализа всех доступных лет можно использовать:

```
nssp_tx_all_years.csv
```

Для анализа только данных за 2024 год:

```
nssp_tx_2024.csv
```

Очищенные версии файлов также доступны в директории `outputs/`.

## Источник данных

Проект использует данные:

**CDC NSSP Emergency Department Visit Trajectories**

Набор данных доступен через платформу Socrata.

Dataset:

```
rdmq-nq56
```

Данные могут использоваться для анализа посещений отделений
неотложной помощи и связанных с ними показателей.
